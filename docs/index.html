Z8

Android에서 사용하는 개발 터미널

기기 내부에서 Linux 개발 환경과 여러 터미널 세션, 로컬 웹 미리보기를 제공합니다. 공식 CLI는 사용자가 직접 설치하고 자신의 계정으로 인증해 사용합니다. Z8 자체 AI 모델 서버나 공용 계정은 제공하지 않습니다.

정식 앱 출시는 준비 중입니다. 소스 공개와 Play Store 출시는 별도 단계입니다.

  • 개인정보처리방침기기 내 정보 처리, 외부 서비스와 데이터 삭제 방법
  • 소스 저장소프로젝트 소개, 빌드 방법과 기여 안내
  • v0.1.0-rc1 소스 ZIP수집한 패키지 소스와 빌드 자료
