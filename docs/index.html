Z8

A development terminal for Android

Run Linux development environments, multiple terminal sessions, and local web previews on your device. Install official CLIs explicitly and sign in with your own accounts. Z8 does not provide its own AI model server or shared accounts.

The app is being prepared for release. Publishing source code and launching on the Play Store are separate steps.
