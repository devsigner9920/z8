REVIEW INFORMATION · 0.1.0-rc8

A local development terminal for Android

Z8 provides project Linux environments, multiple terminal sessions and local web previews. Z8 has no account system, model server, shared provider accounts, advertising or in-app purchases.

This page provides review materials. The source preview and demonstrations do not represent a Play Store approval or a publicly released app binary.

Access the core app

  1. Open Z8 and review the setup disclosures. Choose Start setup to unpack the included development environment. No tool downloads are required for this base step.
  2. Create or open a project. Open a terminal and run a local command such as pwd or printf. Select Python or other tools from the project Tools screen when needed.
  3. Add another terminal, switch between sessions, or start a local development server and open its localhost address in the preview.
  4. Use Settings to read the privacy, data deletion, environment and open-source notices.

These core functions require no Z8 or AI-provider login. Optional official CLI clients require the user's own provider authentication and any applicable subscription or usage fees. The videos below do not demonstrate provider sign-in or a model request.

Current foreground-service behavior

Interactive terminal sessions use a dedicated special-use foreground service. Finite environment preparation, selected tool installation and project-file deletion use a separate data-sync service. Each task starts from a visible user action. The two service types are not enabled together for every operation.

The Project tasks notification provides Stop tasks. Android data-sync timeouts and this action cancel the finite tasks, preserving unrelated interactive terminals. Interrupted setup or installation requires an explicit retry; completed stages and project files are checked again. Interrupted deletion can leave a partly deleted project and offers an explicit retry. Android's Stop action for the entire app terminates all its processes.

The four silent recordings below show the exact final rc8 candidate on dedicated Android emulators. Their captions distinguish actions visible in each clip from separately recorded checks. They do not establish that every device or provider sign-in flow has been tested.

Executable delivery and source

The app bundles a host runtime, PRoot and a Linux filesystem. The initial base is included. Selecting tools downloads native Linux packages, Node.js or official CLI binaries. Optional daily version checks retrieve public metadata only; they do not install code. PRoot uses Android's kernel and app UID; it is not a separate security virtual machine.
