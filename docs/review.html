A local development terminal for Android

Z8 provides project Linux environments, multiple terminal sessions and local web previews. Z8 has no account system, model server, shared provider accounts, advertising or in-app purchases.

This page provides review materials. The source preview and demonstrations do not represent a Play Store approval or a publicly released app binary.

Access the core app

  1. Open Z8 and review the setup disclosures. Choose Start setup to prepare the development environment using an internet connection.
  2. Create or open a project. Open a terminal and run a local command such as python3 --version.
  3. Add another terminal, switch between sessions, or start a local development server and open its localhost address in the preview.
  4. Use Settings to read the privacy, data deletion, environment and open-source notices.

These core functions require no Z8 or AI-provider login. Optional official CLI clients require the user's own provider authentication and any applicable subscription or usage fees. The videos below do not demonstrate provider sign-in or a model request.

Terminal foreground service

A user opens a terminal and starts a command. The ongoing notification makes the active session visible while switching apps. Stopping the service terminates its sessions and child processes; reopening the app does not silently replay commands.

Download the terminal demonstration. Silent screen recording; the visible actions demonstrate session start, background operation and stop.

Environment preparation foreground service

Preparation starts after the user presses Start setup. Progress remains visible in the app and through Android's foreground-service controls. It downloads and installs development packages; the operation can be stopped through Android's active-app controls and resumed through the app.

Download the preparation demonstration. Silent screen recording; it demonstrates initiation and service controls, rather than every minute of package installation.

Executable delivery and source

The app bundles a host runtime, PRoot and a Linux filesystem. Preparation downloads additional native Linux packages and Node.js. Optional CLI installation downloads official binaries. PRoot uses Android's kernel and app UID; it is not a separate security virtual machine. This description does not claim a policy exception has been approved.
