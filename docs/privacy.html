Z8 Privacy Policy

This policy explains the information Z8 handles, connections to external services, and how to retain and delete data.

Effective date: November 2, 2026

1. Z8's role

Z8 is a development tool that provides project Linux environments and terminals on Android. Z8 does not operate its own user accounts or AI model server. It does not provide advertising, usage analytics, or automatic error reporting.

2. Information processed on your device

Z8 processes project names and source files, Linux environments, settings, shell history and CLI credentials in each project's HOME, app settings, and notification records in app storage.

The notification integration records event types, times, and project and session names and identifiers. It does not copy the original text of prompts or commands into notification records.

The internal preview may store cookies, site storage, and caches from development servers you visit. All projects share this preview data, which is separate from CLI credential files.

3. Network connections and external services

Downloading development environments and tools connects to the selected distribution servers, which receive your IP address and download request information. Git, CLIs, package installation tools, and development servers you run may access the network according to their commands and settings. Web pages opened in the preview may also contact external servers according to their page code.

External CLIs such as Codex and Claude Code authenticate with the services and accounts you choose. They may send inputs, source code, command results, and other information to those services. The actual information transmitted, diagnostic data, retention periods, and deletion procedures depend on the installed tool's version and settings and the provider's policies. Each external service's account, subscription, and terms apply separately.

Running locally does not mean that AI processing or every task happens offline. Review external services' retention and transmission policies before entering sensitive information.

External websites and sign-in flows open in a window of the device browser. Those browsers and websites apply their own privacy policies. Z8 does not delete external browser sign-in information or external service accounts on your behalf.

4. Protection and retention

Z8 uses Android app-specific storage and does not allow automatic app backup. External authentication URLs are not written to saved screen state or notification records. The protection of CLI credential files depends on the tool. Z8 does not guarantee that all credentials are stored in a separate encrypted vault.

Files are organized separately for each project, but PRoot is a development environment that shares the Android kernel and app permissions. It is not a security virtual machine. Z8 does not guarantee that tools running with the same app permissions are blocked from accessing other projects or credential files. Run only code and tools you trust.

Project data may remain until you delete the project or clear the app's data. Conversations and history recorded by a CLI depend on that tool's settings.

The app keeps up to 256 notification records. At the limit, new records may replace older records that have been read or belong to ended sessions. You can also clean up records in the notification screen.

5. How to delete data

Closing a terminal

Closing a running session does not delete project files, shell history, or saved CLI sign-in information.

Signing out of an external CLI

Use the installed tool's official sign-out command within that project. Check the help for your installed version first. Local sign-out or deletion of credential files does not guarantee deletion of an external service account or revocation of issued tokens. Manage connected apps, sessions, and tokens directly in the provider's account settings. Custom credential paths or environment variables may need separate attention.

Deleting a project

Long-press a project's name in the project list to delete it. After running sessions are stopped, Z8 deletes that project's source files, Linux environment, HOME, and project settings. CLI credentials and history in that HOME are deleted as well. Save any files you need first.

This does not include other projects, app-wide notification records, preview data, external browsers, or information on external servers. Files in unreadable projects are preserved rather than automatically deleted.

Deleting preview data

In Settings, confirm the preview-data deletion action to remove cookies, site storage, caches, and service workers from the internal WebView shared by all projects. Open previews are stopped, and the result is shown after WebView reports completion. If the installed WebView does not support this operation, the app provides update guidance.

This does not delete project files, CLI credentials, or external browser sign-ins. Terminals and development servers continue running. Visiting a page again may store new data.

App notification records

The history cleanup action in the notification screen removes read notifications and records belonging to ended sessions. It does not approve or reject CLI requests.

All app data

Clearing Z8's app data in Android Settings deletes its local data, including projects. Manage data already sent to external services and information in external browsers separately.

6. This website and inquiries

This information website includes no advertising, visitor analytics, external fonts, or scripts. GitHub Pages, which hosts the site, logs and stores visitors' IP addresses for security purposes. See GitHub Pages data collection information and the GitHub Privacy Statement for details.

For privacy inquiries, contact ethsy2462@gmail.com. When you email an inquiry, the email address and message you send are delivered to the operator through the email service. Do not send passwords, authentication tokens, signing keys, or actual CLI credential files.

For information held by external services, use the relevant provider's inquiry and deletion procedures. Z8 has no user accounts of its own. Follow the instructions above to delete the app's local data.
