내부 미리보기는 방문한 개발 서버의 쿠키·사이트 저장소·캐시를 기기에 보관할 수 있습니다. 이 미리보기 데이터는 모든 프로젝트가 공유하며 CLI의 인증 파일과 별개입니다.

## 보호와 보관 기간

Z8는 Android 앱 전용 저장소를 사용하며 앱의 자동 백업을 허용하지 않습니다. 외부 인증 URL은 저장된 화면 상태나 알림 기록에 쓰지 않습니다. CLI 인증 파일의 보호 방식은 해당 도구에 따르며, 모든 인증 정보가 별도 암호화 저장소에 보관된다고 보장하지 않습니다.

프로젝트마다 파일을 나누지만 PRoot 환경은 Android 커널과 앱 권한을 공유하는 개발 환경이며 보안 가상 머신이 아닙니다. 같은 앱 권한으로 실행되는 도구에 대해 다른 프로젝트나 인증 파일의 접근 차단을 보장하지 않습니다. 신뢰하는 코드와 도구만 실행하세요.

프로젝트 데이터는 사용자가 프로젝트를 삭제하거나 앱 데이터를 지울 때까지 남을 수 있습니다. CLI가 기록하는 대화·히스토리는 도구 설정에 따라 달라집니다. 앱 알림 기록은 최대 256개이며, 한도에 도달하면 읽었거나 종료된 오래된 기록을 새 기록으로 대체할 수 있습니다. 알림 화면에서도 기록을 정리할 수 있습니다.
