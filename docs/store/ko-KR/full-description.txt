Z8는 Android에서 Linux 개발 도구와 프로젝트 작업 공간을 사용할 수 있는 로컬 개발 터미널입니다.

프로젝트별로 작업 정리
소스 파일, 홈 디렉터리, 개발 환경을 프로젝트별로 관리하세요. 여러 터미널 세션을 열고 프로젝트 사이를 이동할 수 있습니다.

익숙한 개발 도구 사용
포함된 Linux 터미널부터 시작하고 프로젝트마다 필요한 도구를 선택하세요. 도구 화면에서 기본 필수 구성요소, 권장 Python·Git, 선택 가능한 Node.js·GitHub CLI·tmux·빌드 도구를 구분해서 볼 수 있습니다. Android 기기에서 명령을 실행하고, 터미널 도구로 파일을 편집하고, 저장소 작업을 할 수 있습니다.

선택하면 Z8를 열 때 하루 한 번 Codex·Claude Code·Node.js의 공식 버전 정보를 확인합니다. 설치와 업데이트는 직접 선택했을 때만 시작합니다. 최신 버전 표시가 해당 버전의 호환성을 보장하지는 않습니다.

로컬 웹 프로젝트 미리보기
기기에서 실행 중인 개발 서버를 앱 내부 미리보기에서 열 수 있습니다. 외부 웹사이트와 로그인 페이지는 기기의 브라우저에서 열립니다.

원하는 공식 CLI 실행
Z8는 Codex와 Claude Code 등 지원되는 공식 CLI를 로컬 환경에 설치하고 실행할 수 있도록 돕습니다. 사용자가 자신의 공급자 계정으로 직접 로그인합니다. 도구의 호환성은 설치된 버전과 기기에 따라 다릅니다.

Z8는 터미널과 개발 환경을 제공합니다. 자체 AI 모델 서비스, 공용 계정 또는 AI 사용량을 제공하지 않습니다. 외부 서비스의 계정 요건, 요금과 약관은 별도로 적용됩니다. 해당 도구는 입력과 소스 코드를 외부 공급자에게 전송할 수 있습니다.

작업 환경 설정
테마를 선택하고 앱 표시 언어를 영어 또는 한국어로 변경할 수 있습니다. 기본 언어는 영어입니다. 설정에서 개인정보처리방침, 로컬 데이터 삭제 안내와 오픈소스 고지를 확인할 수 있습니다.

시작 전 확인
- ARM64 Android 기기가 필요합니다. 설정상 최소 버전은 Android 9이며, 도구별 호환성은 다를 수 있습니다.
- 초기 준비는 포함된 Linux 이미지를 풀며 기기 저장공간을 사용합니다. 선택한 도구의 다운로드·업데이트와 외부 서비스 이용에는 네트워크 연결이 필요합니다.
- 루팅이나 별도의 Termux 앱 설치가 필요하지 않습니다.
- 프로젝트 폴더는 구분되지만 보안 샌드박스가 아닙니다. 신뢰하는 코드와 도구만 실행하세요.

Z8는 GPL-3.0-only 조건으로 공개된 오픈소스 앱이며, 별도 라이선스가 있는 구성 요소는 각자의 조건을 따릅니다. 외부 도구와 서비스에도 자체 라이선스와 약관이 적용됩니다. Z8는 Termux, OpenAI 또는 Anthropic의 공식 제품이 아닙니다.
